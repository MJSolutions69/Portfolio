# MJ Solution Portfolio

GitHub Pages-ready static portfolio for MJ Solution.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive layout
- iOS-style glassmorphism
- Red / black / white visual system

## Included
- Full homepage
- 129-project All Projects page
- 8 featured homepage projects
- React projects: 247 Kabaddi and Predawn HR Portal
- 24-testimonial carousel
- Responsive mobile navigation
- WhatsApp + email floating contact buttons
- Professional personal-photo assets for hero, About and Process sections

## GitHub Pages
Upload all files in this folder to the repository root and enable GitHub Pages from the repository settings.
